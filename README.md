# Blog Post Application

## About
The Blog Post Application is a simple web project built using HTML, CSS, and JavaScript. It allows users to manage blog posts through an interactive user interface.

## Features
- View existing blog posts
- Add new blog posts
- Edit blog post titles
- Edit blog post content
- Delete blog posts with confirmation
- Display posts in a grid layout
